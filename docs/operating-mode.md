# Operating mode / Modo de operação

The user authorized autonomous work inside this repository: implement approved scope, test, review, commit, and push to GitHub without waiting for per-task confirmation.

O usuário autorizou trabalho autônomo dentro deste repositório: implementar o escopo aprovado, testar, revisar, commitar e enviar ao GitHub sem aguardar confirmação por tarefa.

Deployment remains outside this authorization. The user configures EasyPanel from the GitHub repository; do not modify VPS services, DNS, secrets, or EasyPanel settings directly.

O deploy permanece fora desta autorização. O usuário configura o EasyPanel a partir do repositório GitHub; não modifique diretamente serviços da VPS, DNS, segredos ou configurações do EasyPanel.
